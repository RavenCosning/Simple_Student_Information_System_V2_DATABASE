# Simple Student Information System V2

## Overview

A Java-based Student Information System using SQLite for persistent storage.
This version implements full CRUDL operations (Create, Read, Update, Delete, List) with search, sorting, and pagination features through a desktop GUI.

---

## Features

* CRUDL operations for:

  * Students
  * Programs
  * Colleges
* Search functionality
* Sorting and pagination
* SQLite database integration
* GUI built with Java Swing (FlatLaf)

---

## Technologies

* Java
* NetBeans
* SQLite (JDBC)
* FlatLaf

---

## Project Structure

* `src/` – source code
* `lib/` – external libraries
* `nbproject/` – NetBeans configuration
* `student.db` – database file
* `build.xml` – build script

---

## How to Run

**Using NetBeans (recommended):**

1. Open NetBeans
2. Click `File → Open Project`
3. Select this project folder
4. Click `Run`

---

## Database

* Uses SQLite
* File: `student.db`
* Automatically initialized and connected on startup
